# Coin Dash 3D

A 3D arcade game I made in Godot 4 with GDScript. Move the cube with the arrow keys, collect the spinning coin, and avoid the red enemy. You have 30 seconds.

## How to play
- Arrow keys to move
- Touch the gold coin to score
- Avoid the red cube
- Press Space to restart

## What I learned
- Moving from 2D to 3D in Godot
- Creating objects, materials, and movement in code
- Debugging errors by reading the message and line number
